# before-i-go

A small page for friends to leave a memory or two before I leave New York.

- `index.html` — the whole site (gallery intro + two questions, each answerable by writing, recording video, or recording voice).
- `supabase-setup.sql` — run once in the Supabase SQL editor to create the response table and storage bucket.

No personal data lives in this repo. Responses and any real photos/clips are stored in Supabase, not in git.
